PENGGUNA

Tambah Pengguna

Akaun boleh didaftarkan terus menggunakan Google atau email. Pengguna baharu akan berada dalam status Menunggu sehingga Admin meluluskan akaun. Admin boleh menetapkan nama, role dan status dari halaman Pengurusan Pengguna.

Langkah
  1. Pengguna daftar/log masuk menggunakan Google atau email.
  2. Pengguna baharu muncul sebagai Menunggu.
  3. Admin buka menu Pengguna.
  4. Tekan ✓ Lulus atau ubah status kepada Diluluskan.
  5. Tetapkan role Guru / Nazir / Admin jika perlu.
