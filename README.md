# SK@S DIGITAL — V1

Sistem Evidens Digital SK@S untuk Instrumen K@S Edisi 2026.

## V1 yang tersedia
- Dashboard kesiapsiagaan eviden
- Struktur Kekuatan Kami, Pengurusan Kami dan Pencapaian Kami
- Senarai Standard/Aspek
- Carian pantas
- Tambah eviden
- Metadata eviden: kategori, aspek, pemilik, tarikh, URL, catatan
- Simpan data menggunakan `localStorage`
- Rekaan responsif untuk desktop/tablet

## Cara guna di GitHub Pages
1. Upload semua fail ke satu repository GitHub.
2. Pastikan `index.html` berada di root repository.
3. Settings → Pages → Deploy from branch → pilih `main` / root.
4. Buka URL GitHub Pages yang diberikan.

## Penting
V1 belum menggunakan database awan. Eviden sebenar seperti PDF/gambar tidak disimpan dalam GitHub melalui V1. Medan URL disediakan supaya dokumen boleh diletakkan di Google Drive/OneDrive dahulu.
